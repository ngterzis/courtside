# CLAUDE.md

React 18 + TypeScript + Vite frontend for Courtside. The API lives in a separate repo
(courtside-backend); `docs/BACKEND.md` is the contract between them.

## Commands

- `npm run dev:mock`: run the app with no backend (MSW serves `src/mocks/api.ts`)
- `npm run lint && npm run format:check && npm run typecheck && npm test`: fast checks, run before every commit
- `npm run test:e2e`: Playwright E2E + axe accessibility tests; builds the app first, so it's slower
- `npm run format`: fix formatting. CI fails on unformatted code
- `npm run screenshots`: regenerate `docs/screenshots` after visible UI changes

Node 22 (`.nvmrc`). First E2E run needs `npx playwright install chromium`.

## Conventions

- Import from `src` with the `@/` alias.
- Server data goes through a typed hook in `src/lib/queries.ts` that calls `apiFetch`. Don't
  call `fetch` directly, except for the chat stream.
- Styling is Tailwind with the tokens in `tailwind.config.js` (`primary`, `accent`, `ink-*`,
  `paper`). Avoid hard-coded hex colours in components.
- Tests sit next to the code (`foo.test.ts`). Query by role, label or text, not CSS classes.
- Each screen is lazy-loaded in `src/App.tsx`, so route files need a default export.

## Keep in sync

- **API changes**: update `docs/BACKEND.md`, the types in `src/types`, and the mock in
  `src/mocks/api.ts`. `src/mocks/api.test.ts` lists every endpoint the app calls; add new
  ones there.
- **Chat SSE format** (`data: {"text":"..."}` then `data: [DONE]`) is shared by the backend,
  `src/lib/sse.ts` and the mocks. Don't change one side alone.
- **Fixture stats**: precomputed percentages in `src/mocks/fixtures.ts` must match the
  formulas in `src/lib/stats.ts`. A test checks this.

## Gotchas

- Text colours must pass WCAG AA; `e2e/accessibility.spec.ts` fails otherwise. `ink-50` is
  the lightest grey allowed for text. `ink-30` and `ink-15` are for borders and decoration.
- Pushes to `main` deploy to production after CI passes. Work on a branch.
- `public/mockServiceWorker.js` is generated by MSW. Don't edit it by hand.
